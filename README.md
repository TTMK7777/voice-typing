# voice-typing

ローカル完結の日本語音声入力ツール。Whisper(GPU)で文字起こしし、**今アクティブなウィンドウのカーソル位置に自動入力**する。全アプリで使える。**音声もテキストも一切外部に出ない**（→ [プライバシー & セキュリティ](#プライバシー--セキュリティ) / [SECURITY.md](SECURITY.md)）。

> 動作前提: **Windows + NVIDIA GPU (CUDA)**。現状コードは `device="cuda"` 固定のため CPU では動きません（CPU 対応は今後の課題）。

## インストール

```powershell
# プロジェクトのフォルダに入ってから実行する
cd path\to\voice-typing
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> PowerShell では相対パスの実行ファイルに `.\` を付ける(`python.exe` を直接打つと
> コマンド名と誤解される)。cmd.exe でも `.\` 付きで動く。

初回起動時に Whisper モデル（`large-v3` / `small`）を Hugging Face から**自動ダウンロード**します（モデル取得のみ。以降はネット接続不要）。

デスクトップアイコンから起動したい場合は、続けて次を実行します（任意）。

```powershell
powershell -ExecutionPolicy Bypass -File .\create_shortcut.ps1
```

デスクトップに「VoiceTyping」ショートカットが作られます（`pythonw.exe` 起動なので黒いコンソール窓が出ません）。

## 起動

- `run_gui.bat` をダブルクリック
- または上記で作った**デスクトップの「VoiceTyping」アイコン**(黒窓が出ないので常用向き)
  - タスクバーに置きたい場合はアイコンをタスクバーにドラッグ

起動すると画面にマイクボタンが浮かぶ。**灰=ロード中 → 青=待機**になれば準備OK。

**灰のうちから録音を始めてかまいません。** マイクにモデルは要らないので、喋っている間に
ロードが裏で進み、停止時にまだ届いていなければそこで残りだけ待ちます(プレビュー欄に
「モデル読込中」と出ます)。起動してすぐ喋り始めるのが一番速い使い方です。

毎回の起動待ちをなくしたい場合は、Windows サインイン時に自動起動させます(任意)。

```powershell
powershell -ExecutionPolicy Bypass -File .\create_shortcut.ps1 -Startup
```

スタートアップフォルダにもショートカットが入り、常駐したボタンをそのまま使えます。
やめるときは `shell:startup` を開いて「VoiceTyping」を削除してください。

## 使い方

1. 入力したいアプリにカーソルを置く
2. **マイクボタンをクリック** or **Ctrl+Alt+Space** で録音開始(赤)
3. 喋る(録音中はボタン上のパネルに暫定テキストがリアルタイム表示)
4. もう一度押すと確定(橙)→ アクティブウィンドウに入力
5. マイクボタンは**ドラッグで移動**、プレビューパネルも個別に移動可
6. 終了は**右クリック → 終了**

## ハンズフリー(ウェイクワード待受)

ボタンもキーも触らずに口述を始めたいとき用。**既定は OFF**。

- **ON/OFF**: `Ctrl+Alt+L`、または**右クリック → ウェイクワード待受**
- ボタンの色が状態を表す: **緑 = 待受中** / **赤 = 連続口述中(喋ると貼られる)**

**ウェイクワードを言うのは最初の一度だけ**です。あとは「喋る → ちょっと黙る → 貼られる」を
繰り返します。一文ごとにボタンを押す必要はありません。

```
（緑＝待受）  「やっほークロード」
      ↓
（赤＝連続口述）  喋る → 0.5秒黙る → 貼り付け
                  喋る → 0.5秒黙る → 貼り付け
                  喋る → 0.5秒黙る → 貼り付け  … 止めるまで繰り返す
```

- **止め方**: マイクボタンをクリック / `Ctrl+Alt+Space` / 30 秒何も喋らない
- 赤の間は `Enter` を遮断しません。貼り付いた文をそのまま `Enter` で送信できます
  (手押し録音のときだけは、誤送信防止のため録音中の `Enter` を遮断します)
- 認識したテキストはパネルに表示されてから貼られます(何が入力されるか目で確認できます)
- 何を拾って何と判定したかは黒窓に出ます。**デスクトップ/タスクバーのアイコンから起動すると
  黒窓が無いのでログが見えません。**うまく動かないときは `run_gui.bat` から起動してください

```
[wake] 'やっほーくろーど' -> HIT
[session] 開始: 喋る → 黙る → 貼り付け。止めるにはボタン/Ctrl+Alt+Space
[timing] 音声 3.8s / 確定 0.35s / 貼付 0.05s / 体感 0.90s
```

`体感` が「喋り終わってから貼られるまで」の実測（＝ `DICTATE_SILENCE_SEC` + 確定 + 貼付）。
遅いと感じたときは、この内訳のどれが大きいかを見て調整してください。

- **音声コマンドは従来どおりトリガー語が必要**です。口述中も「クロード、クリア」と
  言ってください(ウェイクワードだけでコマンドが撃てると、誤発火時に Enter まで飛ぶため)
- 誤発火のリスクと調整方法は [SECURITY.md](SECURITY.md) の「既知の限界」を参照

## 音声コマンド(Claude Code のスラッシュコマンドを声で実行)

「**クロード、クリア**」「**クロード、コンパクト**」のように「トリガー語+コマンド語」を話すと、
テキスト貼り付けの代わりに `/clear` `/compact` を注入して Enter まで自動送出する。

| 発話 | 実行されるコマンド |
|---|---|
| クロード、クリア | `/clear` |
| クロード、コンパクト | `/compact` |
| クロード、コンパクト、○○の話 | `/compact Focus on ○○の話` |

- 誤発火対策: トリガー語(クロード/Claude)必須。「クリアしてください」のように
  コマンド語の後へ余計な語が続く場合は実行しない(コンパクトの引数のみ例外)
- コマンド表は `core.py` の `VOICE_COMMANDS` で編集可
- Enter は2回送出(Claude Code の補完ポップアップに1回目が食われた場合の保険。
  空プロンプトへの2回目は無害)

## 調整ポイント

| やりたいこと | 場所 |
|---|---|
| よく使う語/誤変換しやすい語を覚えさせる | `vocab.txt`(1行1語。**大事な語ほど下に**書く。下記参照) |
| プレビュー更新の速さ | `app_rt.py` の `PREVIEW_INTERVAL`(小さいほど速い) |
| プレビューを更に高速化 | `app_rt.py` の `PREVIEW_MODEL = "tiny"` |
| プレビュー表示文字数 | `app_rt.py` の `MAX_PREVIEW_CHARS` |
| ホットキーを変える | `app_rt.py` / `app.py` の `HOTKEY` / `WAKE_HOTKEY` |
| 新しい幻覚フレーズを消す | `core.py` の `HALLUCINATIONS` に1行追加 |
| ウェイクワードを変える | `wake_word.py` の `_WAKE_RE`(表記揺れを吸収するため正規化後のパターン) |
| 発話の拾い始め/切れ目が合わない | `wake_listener.py` の `VAD_SPEECH_PROB` / `VAD_SILENCE_PROB`(Silero VAD の確率しきい値) |
| 喋り終わりから貼られるまでの間 | `app_rt.py` の `DICTATE_SILENCE_SEC`(既定 0.5 秒。短いほど速いが文中の「間」で細切れに貼られやすい) |
| 口述セッションが自動で終わるまでの時間 | `app_rt.py` の `SESSION_IDLE_TIMEOUT_SEC`(既定 30 秒) |

### 固有名詞が誤変換されるとき

`vocab.txt` に足すのが唯一効く手です。文脈を長くしても直りません
(実測: 「山王病院に行きます」だけでも、前後に文を足した長い発話でも同じく `産脳病院` /
`三能病院` になり、`vocab.txt` に 1 語足した時だけ `山王病院` になった)。

**`vocab.txt` には上限があります**。Whisper は認識ヒントの**末尾 223 トークン**しか読まず、
あふれた先頭は警告なく捨てます。日本語の固有名詞は 1 語あたり約 5 トークンなので、
**入るのは 30 語ほど**です。超えると起動時に `[vocab]` 警告が出るので、
そうなったら使わない語を消してください。捨てられるのは先頭からなので、
**よく使う語ほどファイルの下**に書くと生き残ります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `core.py` | 録音・文字起こし・貼り付け・幻覚除去・音声コマンド・ウェイクワード用のマイク監視。**OS に触れる処理は全部ここ** |
| `app_rt.py` | GUI 本体(フローティングボタン + リアルタイムプレビュー)。`core.py` を呼ぶ |
| `wake_word.py` | ウェイクワードの判定(文字列だけ。OS・マイク・GPU に触れない) |
| `wake_listener.py` | 発話区間の切り出し(Silero VAD)とウェイク判定の呼び出し(マイクは持たず、`core.py` から音声ブロックを受け取る) |
| `app.py` | ボタンのみの簡易 GUI(プレビューなし)。同じく `core.py` を呼ぶ |
| `cuda_setup.py` | CUDA DLL のパス登録(faster-whisper の GPU 動作に必須) |
| `vocab.txt` | 認識のヒント語彙(`vocab.example.txt` をコピーして作る) |
| `make_icon.py` / `create_shortcut.ps1` | アイコン・ショートカット生成 |
| `tests/` | 単体テスト |

GUI は 2 つとも `core.py` の `VoiceCore` を呼ぶだけで、独自に録音や貼り付けをしている箇所はありません
（監査するなら `core.py` だけ読めば足ります。詳細は [SECURITY.md](SECURITY.md)）。

## テスト

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- 標準ライブラリの `unittest` のみ。**追加のテスト依存はありません**（アプリの依存は必要です）
- マイク・GPU・Whisper モデルを必要としません(録音とモデル呼び出しは差し替え)

## 構成技術

- 文字起こし: faster-whisper（確定=`large-v3` / リアルタイム暫定=`small`、GPU/CUDA）
- 発話区間の検出: Silero VAD（faster-whisper 同梱、ONNX/CPU。追加依存なし）
- GUI: PySide6（フォーカスを奪わない `WS_EX_NOACTIVATE` ウィンドウ）
- 入力送出: pyperclip（クリップボード）+ pynput（ホットキー / キーストローク）

## プライバシー & セキュリティ

- **音声もテキストも一切外部に出ません。** 録音・文字起こし・貼り付けはすべてあなたの PC 内で完結します。
- テレメトリ・解析・リモートログはありません。コードはネットワークへテキストを送りません。
- 唯一の外部接続は**初回のモデルダウンロード**（Hugging Face）のみで、あなたのデータは出ません。
- 本アプリはグローバルなキー入力監視・キーストローク送出・クリップボード操作を使うため、**アンチウイルスが誤検知することがあります**。その理由・何を「しないか」・監査方法は **[SECURITY.md](SECURITY.md)** に明記しています。
- **既知の限界**: 確定テキストは貼り付けの瞬間だけグローバルクリップボードに乗ります（直後に元内容を復元）。詳細は SECURITY.md の「既知の限界」参照。

## このプロジェクトの位置づけ

**作者が自分で使うために作った個人用ツールで、現在の状態で完成としています。**
放置しているのではなく、必要な機能が揃ったのでそこで止めた、という意味です。

- **機能追加は基本的に行いません。** 作者の個人的な必要に応じて、まれに追加することはあります。
  不具合の修正は行います
- 動作前提（Windows + NVIDIA GPU）は作者の環境に合わせた割り切りです。CPU 対応は歓迎する改善テーマですが、作者が着手する予定は今のところありません
- Issue / Pull Request は歓迎しますが、個人プロジェクトのため**返答は遅れます**

設計上の優先順位（迷ったときにこの順で決めています）:

1. **完全ローカル** — 音声・テキストを外部に出さないことは、他の何より優先します
2. **日本語の認識品質** — 句読点・同音異義語・幻覚除去
3. **軽さ** — 依存を1つ増やすことのコストを、機能の魅力より重く見ます

### 検討して見送ったこと

- **CPU 対応 / exe 配布**: 使える人は確実に増えますが、個人用途では必要ないため着手していません。
  やるなら `core.py` の `device="cuda"` 2 箇所と `requirements.txt` の `nvidia-*` が起点です
- **CI**: GPU 前提の環境を CI で用意できず、通らないワークフローを置くと「動いているように見えて動いていない」状態になるため置いていません

### 過去に試して外した機能

同じ道を再度通らないための記録です。

- **LLM による整形（校正・敬語・英訳）**: Whisper 確定の後段に直列1段入るため体感が遅くなり、
  句読点誘導プロンプト + `vocab.txt` で下地が足りていたので上積みが速度コストに見合わなかった。
- **常時リスニングモード（声紋認証 + VAD の常時待受）**: 大音量（TV/動画等）がマイクに入り続けた後、
  音を止めても本人の声への一致精度が下がったまま戻らない問題が解決できなかった。
  アプリ再起動・PortAudio 再初期化・声紋再登録・Windows のオーディオ強化オフでも再現し、
  マイク本体（ハードウェア内蔵）の AGC / ノイズ抑制の適応が原因と推定。
  精度が信頼できない機能を残すより外す判断をした。
  なお現在の**ウェイクワード待受は声紋認証を使いません**（「誰が喋ったか」ではなく
  「何と言ったか」だけで判定する）。上記の故障要因そのものを持たない別設計です。
  代わりに、ウェイクワードを言えば誰の声でも反応します。
