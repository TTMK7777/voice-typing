# voice-typing

ローカル完結の日本語音声入力ツール。Whisper(GPU)で文字起こしし、**今アクティブなウィンドウのカーソル位置に自動入力**する。全アプリで使える。**音声もテキストも一切外部に出ない**（→ [プライバシー & セキュリティ](#プライバシー--セキュリティ) / [SECURITY.md](SECURITY.md)）。

> 動作前提: **Windows + NVIDIA GPU (CUDA)**。現状コードは `device="cuda"` 固定のため CPU では動きません（CPU 対応は今後の課題）。

## インストール

```powershell
# プロジェクトのフォルダに入ってから実行する
cd path\to\voice-typing
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> PowerShell では相対パスの実行ファイルに `.\` を付ける(`python.exe` を直接打つと
> コマンド名と誤解される)。cmd.exe でも `.\` 付きで動く。

初回起動時に Whisper モデル（`large-v3` / `small`）を Hugging Face から**自動ダウンロード**します（モデル取得のみ。以降はネット接続不要）。

## 起動

- **デスクトップの「VoiceTyping」アイコン**をダブルクリック(黒窓なし・推奨)
  - タスクバーに置きたい場合はアイコンをタスクバーにドラッグ
- または `run_gui.bat`(リアルタイム版 GUI)/ `run.bat`(CLI版)

起動すると画面にマイクボタンが浮かぶ。**灰=ロード中 → 青=待機**になれば準備OK。

## 使い方

1. 入力したいアプリにカーソルを置く
2. **マイクボタンをクリック** or **Ctrl+Alt+Space** で録音開始(赤)
3. 喋る(録音中はボタン上のパネルに暫定テキストがリアルタイム表示)
4. もう一度押すと確定(橙)→ アクティブウィンドウに入力
5. マイクボタンは**ドラッグで移動**、プレビューパネルも個別に移動可
6. 終了は**右クリック → 終了**

## 音声コマンド(Claude Code のスラッシュコマンドを声で実行)

「**クロード、クリア**」「**クロード、コンパクト**」のように「トリガー語+コマンド語」を話すと、
テキスト貼り付けの代わりに `/clear` `/compact` を注入して Enter まで自動送出する。

| 発話 | 実行されるコマンド |
|---|---|
| クロード、クリア | `/clear` |
| クロード、コンパクト | `/compact` |
| クロード、コンパクト、○○の話 | `/compact Focus on ○○の話` |

- 誤発火対策: トリガー語(クロード/Claude)必須。「クリアしてください」のように
  コマンド語の後へ余計な語が続く場合は実行しない(コンパクトの引数のみ例外)
- コマンド表は `core.py` の `VOICE_COMMANDS` で編集可
- Enter は2回送出(Claude Code の補完ポップアップに1回目が食われた場合の保険。
  空プロンプトへの2回目は無害)

## 調整ポイント

| やりたいこと | 場所 |
|---|---|
| よく使う語/誤変換しやすい語を覚えさせる | `vocab.txt`(1行1語。認識のヒントに効く) |
| プレビュー更新の速さ | `app_rt.py` の `PREVIEW_INTERVAL`(小さいほど速い) |
| プレビューを更に高速化 | `app_rt.py` の `PREVIEW_MODEL = "tiny"` |
| プレビュー表示文字数 | `app_rt.py` の `MAX_PREVIEW_CHARS` |
| ホットキーを変える | `app_rt.py` / `voice_input.py` の `HOTKEY` |
| 新しい幻覚フレーズを消す | `core.py` の `HALLUCINATIONS` に1行追加 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `core.py` | 録音・文字起こし・貼り付け・幻覚除去の共通ロジック |
| `app_rt.py` | リアルタイム版 GUI(フローティングボタン + プレビュー) |
| `app.py` | ボタンのみの GUI(プレビューなし) |
| `voice_input.py` | CLI版(ターミナルに結果表示) |
| `cuda_setup.py` | CUDA DLL のパス登録(faster-whisper の GPU 動作に必須) |
| `vocab.txt` | 認識のヒント語彙(`vocab.example.txt` をコピーして作る) |
| `make_icon.py` / `create_shortcut.ps1` | アイコン・ショートカット生成 |
| `tests/` | 単体テスト(標準ライブラリ `unittest`、外部依存なし) |

## テスト

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

マイク・GPU・モデルを必要としないテストのみで構成しています(録音とモデル呼び出しは差し替え)。

## 構成技術

- 文字起こし: faster-whisper（確定=`large-v3` / リアルタイム暫定=`small`、GPU/CUDA）
- GUI: PySide6（フォーカスを奪わない `WS_EX_NOACTIVATE` ウィンドウ）
- 入力送出: pyperclip（クリップボード）+ pynput（ホットキー / キーストローク）

## プライバシー & セキュリティ

- **音声もテキストも一切外部に出ません。** 録音・文字起こし・貼り付けはすべてあなたの PC 内で完結します。
- テレメトリ・解析・リモートログはありません。コードはネットワークへテキストを送りません。
- 唯一の外部接続は**初回のモデルダウンロード**（Hugging Face）のみで、あなたのデータは出ません。
- 本アプリはグローバルなキー入力監視・キーストローク送出・クリップボード操作を使うため、**アンチウイルスが誤検知することがあります**。その理由・何を「しないか」・監査方法は **[SECURITY.md](SECURITY.md)** に明記しています。
- **既知の限界**: 確定テキストは貼り付けの瞬間だけグローバルクリップボードに乗ります（直後に元内容を復元）。詳細は SECURITY.md の「既知の限界」参照。

## ロードマップ

- 差別化は **日本語の認識品質（句読点・同音異義語・幻覚除去）** に1点集中
- 「軽量・使いやすい・安全・透明・無料」を価値に
- 軽量化: Whisperサイズ選択（CPU対応）/ exe配布（PyInstaller）+ モデル自動DL

過去に試して**外した**機能（同じ道を再度通らないための記録）:

- **LLM による整形（校正・敬語・英訳）**: Whisper 確定の後段に直列1段入るため体感が遅くなり、
  句読点誘導プロンプト + `vocab.txt` で下地が足りていたので上積みが速度コストに見合わなかった。
- **常時リスニングモード（声紋認証 + VAD の常時待受）**: 大音量（TV/動画等）がマイクに入り続けた後、
  音を止めても本人の声への一致精度が下がったまま戻らない問題が解決できなかった。
  アプリ再起動・PortAudio 再初期化・声紋再登録・Windows のオーディオ強化オフでも再現し、
  マイク本体（ハードウェア内蔵）の AGC / ノイズ抑制の適応が原因と推定。
  精度が信頼できない機能を残すより外す判断をした。
