# 行動規範 / Code of Conduct

このプロジェクトは **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** を行動規範として採用します（日本語版: [Contributor Covenant 日本語](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/)）。

参加者は、Issue・Pull Request・その他このリポジトリ上のあらゆるやりとりにおいて、上記の内容に従うことが期待されます。

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. All participants are expected to abide by it in Issues, Pull Requests, and any other interaction in this repository.

## 報告窓口 / Reporting

| 状況 | 窓口 |
|---|---|
| 規範に反する行為を報告したい | [private security advisory](../../security/advisories/new)（メンテナのみ閲覧可。この窓口を行動規範の報告にも使います） |
| メンテナ自身の行為が問題である場合 | [GitHub への通報](https://github.com/contact/report-abuse) |

報告は可能な範囲で速やかに、報告者のプライバシーを尊重して扱います。

Reports are handled as promptly as reasonably possible, with respect for the reporter's privacy. If the maintainer is the subject of the report, please use GitHub's [report abuse](https://github.com/contact/report-abuse) form instead.
